tabli — self‑contained tables for LLM agents

Built for users with no memory, no eyes, and a token budget.

View on GitHub Watch it work ↓

SYNOPSIS

A real session. The table answers because the table is the program.

DESCRIPTION

A .tbl file is engine, data and manual in a single executable. Run it bare and it prints its own grammar. There is no server, no schema, no install step, no dependency — a table is a ~40 KB file you can copy anywhere, and it keeps answering.

Delete tabli, and your tables won’t even notice.

The engine writes are atomic (temp + rename), serialized by a lock, integrity-checked with crc32. Records are plain text in the same grammar you type — strings backlog.tbl shows your data, readable, at the end of the binary.

offset 0 ┌────────────────────────────────┐ │ ELF engine (~40 KB) │ the program itself engine size ├────────────────────────────────┤ │ header (64 bytes) │ magic · count · last id · crc32 +64 ├────────────────────────────────┤ │ records — plain text lines │ id=7 title='fix lock' status=open EOF └────────────────────────────────┘

COMMANDS

a ./t.tbl a title='fix lock' status=open

Add a record — free key=value fields, no schema. Echoes the record with its new id.

q ./t.tbl q status=open prio>1

Filter with = != > < >= <= ~. Output caps itself to protect the caller’s context window; count answers for near-zero tokens.

g / s / d ./t.tbl s 7 status=done if status=open

Get, set, delete. if is compare-and-swap: a stale belief becomes a teachable error, not silent corruption.

next ./t.tbl next status=open set status=claimed by=me

Atomic take. Two agents calling concurrently always receive different records — a race-free work queue with no orchestrator.

cursor / diff ./t.tbl diff 23-23-aa3e1624-1784903603

Delta sync: an agent waking up with no memory pays ten lines, not the whole table.

DESIGN

  • One grammar everywhere. Stored form = input form = output form. Query results paste straight back into commands.
  • Errors teach. Every error contains the correct usage — an agent self-corrects on the next call.
  • Engine-owned clock. created_at/updated_at come from the engine, never the agent: one field of truth that cannot be hallucinated.
  • Mechanism, not policy. The engine holds only what needs atomicity, the clock, the lock. Everything else is a field convention on top.

SECURITY

The one rule: execute only .tbl files you created. A foreign table is an untrusted binary — inspect it with strings instead (the records are plain text). Output is always shell-safe quoted, so stored data can never smuggle $(commands) into an agent’s next call.

FILES
